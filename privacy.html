Privacy

Lenscape requests camera and location access only when you start a scan. In local mode, your profile and diary metadata stay in this browser. Saved diary photos are stored as reduced-size thumbnails to limit local storage use.

When AI recognition is configured, the compressed scan image and an approximate location hint may be sent through the Lenscape server to the configured OpenAI API to identify and research the landmark. If AI is unavailable, the server may use OpenStreetMap/Overpass, Nominatim, and Wikipedia to suggest nearby landmarks and retrieve public historical information. Those services receive the network requests required to provide their results.

If the optional community leaderboard is enabled, only leaderboard profile fields and server-verified landmark discovery metadata are sent to the configured Supabase project. Diary photos and personal notes are not uploaded to the leaderboard.

Shared travel-map links deliberately omit photos. They contain a compact copy of the places and captions included in the shared map inside the URL fragment, so the receiving browser can render the map without uploading that shared payload to Lenscape.

Do not scan or save private or sensitive photos. You can clear locally saved diary data from Settings. Clearing local data does not automatically delete an already-synced leaderboard record.
